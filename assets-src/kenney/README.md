# Kenney source models (CC0)

Picked from Peter's "Kenney Game Assets All-in-1 3.7.0" folder
(`3D assets/<pack>/Models/GLB format`). CC0 / public domain: free for
commercial use, no credit required.

- `city-commercial/` — City Kit (Commercial): shops, offices, skyscrapers,
  their low-detail versions (far-away stand-ins), awnings, parasols, and the
  colour textures (`colormap.png`, `variation-a/b.png`).
- `city-suburban/` — City Kit (Suburban): houses (`building-type-a` … `u`)
  for the rentable home lots, low fence, planter, colour texture.

These are the SOURCES. `scripts/build-kenney-assets.mjs` packs what the game
uses into `public/models/*.glb`.
